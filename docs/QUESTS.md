# Миссии, диалоги и сюжет «Hateful Chris 2» (из логики оригинала)

## Как устроено в игре
- **Диалог = отдельный кадр** (frame): одна картинка 800×600 с нарисованным текстом + кнопка «Space» (картинка 2738).
  При входе играет звук `questCut` (начало/середина) или `questVictory` (финал миссии). Пробел — следующий кадр.
  Текста как данных нет: он нарисован на картинках (список картинок — в конце).
- **Состояние миссий** хранится в сохранении (`syshcin1.ini`, раздел `status`):
  - `quest1`…`quest8`: 0 — не взята, 1 — взята, 2 — выполнена (у quest3 бывает 3 — после апгрейда меха);
  - `progress` — шаг **текущей** миссии. Он один на всех, поэтому одновременно идёт только одна миссия:
    почти все миссии берутся только при `progress == 0`;
  - `quests` — сколько миссий выполнено (+1 за каждую);
  - `mall` — 1, когда молл взорван (вместо Mall1 грузится Mall1a);
  - `mech`, `mechlevel` — мех куплен / уровень меха.
- Уровень при старте читает эти ключи в свои счётчики (в редакторе они названы бессмысленно: `jump speed`,
  `jump speed 2/3/4`, `Counter`) — таблица соответствий в quests.json, поле `level_counters`.
- Взять новую миссию можно, только если `quests ≤ 3` (кроме Спа и Хоккея — у них проверки нет).

## Основной сюжет
1. Title → новая игра → **Intro 1 → Intro 2 → Intro 3** → Training → Downtown.
2. Свободная игра: миссии 1–8 в любом порядке (по одной за раз).
3. **Похищение:** при входе в Klubkix, если выполнено 4 или 5 миссий (`quests` = 4..5) → диалог **trix abduct**.
   - мех не куплен → **cuzin les** → Gerbil Minigame; мех куплен → сразу Gerbil Minigame.
   - Если войти в Klubkix, имея 6+ миссий, похищение не случится (возможный тупик оригинала).
4. **Gerbil Minigame:** хомяком включить 2 рубильника (↑, звук spaceSwitch), затем выход — зона x359..450 y18..132, ↑ →
   **Before last last → before last battle** → Last Stage wave 1 → 2 → 3 → Dana.
5. **Dana:** когда Дана доиграет анимацию 14 (смерть) → **end 1 → end 2** → концовка по деньгам:
   - ≤ 2000 $ — **bad end** → Title;
   - 2001…5000 $ — **okay end**: сохранение сбрасывается (новая игра) → экран Save;
   - ≥ 5001 $ — **good end**: новая игра со **всем оружием**, quests=20 (миссии больше не берутся) → экран Save.
